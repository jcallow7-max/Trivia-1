# Project 3 - Trivia

Submitted by: **Jackson Calloway**

**Underground Trivia** is a trivia supposed to be a reference to Hyperpop Daily and reference online rap memes and culture with trivia.
Time spent: **12** hours spent in total

## Required Features

The following **required** functionality is completed:

- [x] User can view the current question and 4 different answers
- [x] User can view the next question after tapping an answer
- [x] User can answer at least 3 different questions

The following **optional** features are implemented:

- [x] User can use the vertical orientation of the app on any device
- [x] User can track the question they are on and how many questions are left
- [x] User can see how many questions they got correct after answering all questions
- [x] User can restart the game after they've finished answering all questions

The following **additional** features are implemented:

- [x] Questions are separated into different categories such as Names, Songs, and Aura
- [x] The app uses a custom black, red, and white underground rap-inspired theme
- [x] The final score gives the user a different ranking depending on how many questions they answered correctly
- [x] The restart button allows the user to immediately play through the trivia again
